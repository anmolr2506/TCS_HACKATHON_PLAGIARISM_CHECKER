# TCS_HACKATHON_PLAGIARISM_CHECKER

Basic full-stack web app file structure.

## Project Structure

```text
.
├── client
│   ├── package.json
│   ├── public
│   │   └── index.html
│   └── src
│       ├── App.js
│       └── index.js
└── server
    ├── package.json
    └── src
        ├── app.js
        └── server.js
```

## Quick Start

### Frontend

```bash
cd client
npm install
npm start
```

### Backend

```bash
cd server
npm install
npm start
```
